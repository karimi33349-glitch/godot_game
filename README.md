# Akhoond

Persian word puzzle game built with Godot 4.6.2.

## Version 1

- Portrait mobile layout (1080×1920 design viewport)
- Chapter and level selection
- Progressive level unlocking
- Persistent highest-unlocked progress via `user://save.json`
- Level-complete popup
- Touch and mouse-emulated touch input
- Android debug APK GitHub Actions workflow

## Engine

Godot 4.6.2
