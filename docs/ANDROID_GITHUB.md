# Android debug APK from GitHub Actions

This project uses Godot 4.6.2 and includes an Android debug export preset plus a GitHub Actions workflow.

## Upload to GitHub
1. Create an empty repository on GitHub.
2. Upload/push the **contents** of this folder (the folder containing `project.godot`) to the repository root.
3. Push to `main` or `master`, or run **Actions → Android Debug APK → Run workflow**.
4. Open the completed workflow run and download the `Akhoond-V1-debug-apk` artifact.

## Important
- `.godot/` is generated by Godot and is intentionally not included. Godot recreates it on first import.
- The existing `.import` metadata files are retained.
- The workflow creates a temporary debug signing key; no signing key is stored in this repository. The APK is for testing, not a Play Store release.
- Open `project.godot` in Godot 4.6.2 or compatible 4.6.x to run locally. Check the project on a real Android device before release; an automated export cannot prove identical runtime behavior on every device.
